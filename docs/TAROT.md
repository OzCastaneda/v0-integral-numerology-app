# Correspondencias del Tarot - Arcanos Mayores

Este documento detalla las correspondencias de los 22 Arcanos Mayores del Tarot integradas en la aplicacion.

## Vision General

Cada Arcano Mayor esta conectado con:
- Un **numero** (0-21)
- Una **letra hebrea**
- Un **signo zodiacal** o planeta
- Un **elemento** (Fuego, Agua, Aire, Tierra)
- Correspondencias **corporales**
- **Bloqueos** y problemas psicologicos
- Problemas de **salud** asociados
- **Palabras clave**
- Un **mensaje** espiritual

## Uso en la Aplicacion

La seccion de Tarot en `/tarot` muestra cada Arcano Mayor con:

1. **Cabecera**: Numero, nombre, reduccion numerologica
2. **Descripcion**: Significado general de la carta
3. **Palabras clave**: Tags principales
4. **Correspondencias basicas**: Cabala, Astrologia, Numerologia
5. **Correspondencia corporal**: Partes del cuerpo asociadas
6. **Bloqueos**: Problemas cuando la energia esta bloqueada
7. **Salud**: Problemas fisicos asociados
8. **Mensaje**: Ensenanza espiritual de la carta
